# AssignmentApp

Django assignment app, plus **A2P Atlas** — a single-page world map of A2P SMS sender support by country.

## A2P Atlas

See [`a2p-atlas/README.md`](a2p-atlas/README.md).

**Live:** https://arundas1903.github.io/AssignmentApp/

```bash
cd a2p-atlas
npm install
npm run dev
```

Data is sourced from [awsdocs/amazon-pinpoint-user-guide](https://github.com/awsdocs/amazon-pinpoint-user-guide) / [AWS End User Messaging SMS country support](https://docs.aws.amazon.com/sms-voice/latest/userguide/phone-numbers-sms-by-country.html).
