# SMS Country Map

Django assignment app, plus **SMS Country Map** — a single-page world map of A2P SMS sender support by country.

## SMS Country Map

See [`sms-country-map/README.md`](sms-country-map/README.md).

**Live:** https://arundas.me/a2patlas/

```bash
cd sms-country-map
npm install
npm run dev
```

Publish to the portfolio site:

```bash
npm run publish:arundas -- /path/to/portfolio
```

Data is sourced from [awsdocs/amazon-pinpoint-user-guide](https://github.com/awsdocs/amazon-pinpoint-user-guide) / [AWS End User Messaging SMS country support](https://docs.aws.amazon.com/sms-voice/latest/userguide/phone-numbers-sms-by-country.html).
